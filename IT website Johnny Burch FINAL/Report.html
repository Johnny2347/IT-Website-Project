Accessibility and Responsiveness Report

Accessibility

Making my website accessible to all, and including accomodations for those with impairments

I have taken various steps to make my website more accessible and responsive,
to start with I used a colour checker website (colorsafe.co) to check the
contrast ratio of the colours and text on my website. The website is
aimed to help you find a colour scheme that fits with WCAG guidelines, it
makes sure your colours are at least AA 2. The use of this website ensures
that there is enough contrast between text and background, making it
more acessible for people with visual impairments as the letters stand out more
The image containing my poster has an alternate description, which could be read
by users with read aloud software so they could get a description of the image
to interpret it.



Responsiveness

Resizing, hiding, enlarging and shrinking content so its fit for any screen

I have added features to optimize my websites usability and cater to different
devices with different screen sizes. To ensure my website was responsive
I used media querys and the viewport meta tag to display content differently
depending on the screen size of the device, smaller devices such as mobile
phones get a different menu, with options listed vertically instead of
horizontally for easier use, and font size is made slighly smaller to fit
text on the smaller screens. Larger devices such as laptops or computers
get a menu with options listed horizontally and a larger font. The images
and UI resize based on the size of the device screen, their width and
height are set as percentages of the screen instead of fixed pixel
values, this means they change size with different devices. My website
also includes a footer, with an option to allow the user to return to
the top of the current page they are viewing, this increases usability
and stops the user having to scroll back up manually, I have made sure
that the footer also changes size based on the screen.



Overall look and feel of website

I chose to use two colours to keep the website from looking too cluttered, as
too many colours can make the website confusing and less likely to grab the users
attention, I used blue for the menu UI to match the theme of the
poster and a light grey to provide a high enough contrast ratio for the text.
I could have used a darker shade of grey but this would be unsuitable as it would
not provide a high enough contrast ratio, instead I used a lighter shade which was
more suitable.
